Examples

Ready-made configurations. Download one, change the app and screen names to yours, and you're set.

To use one
  1. Download it, then save it as ~/.mwm.yml (in Finder: Go → Go to Folder…, type ~; files starting with a dot are hidden, ⌘⇧. shows them). If you already have one, keep a copy first.
  2. Open the MWM menu and choose Configure MWM…, then press Apply.
  3. Edit it in the window, or by hand. The documentation explains every field.

# Example: a laptop and an external display. Name each screen, then send windows to it by name.

# hyper + arrows split the external display, hyper + tab throws a window to the other screen.
