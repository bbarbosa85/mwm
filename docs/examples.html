Examples

Ready-made setups. Pick the one closest to how you work, download it, and change what you need. Each one lists what its shortcuts do.

How to use an example

  1. Download it with the button on a card below.

  2. Save it as ~/.mwm.yml, in your home folder. This replaces your current settings, so make a copy first if you have any.

    Easiest way, in Terminal (use the file name you downloaded):

    cp ~/.mwm.yml ~/.mwm.yml.backup    # only if you already have one
mv ~/Downloads/starter.mwm.yml ~/.mwm.yml

    Or in Finder: Go → Go to Folder…, type ~, and drag the file in. Files that start with a dot are hidden; ⌘⇧. shows them.

  3. Open MWM and press Apply and Restart. Choose Settings… from the menu bar, then Apply and Restart. Now change the app and screen names to yours, right in the app.

    More help in the documentation.
