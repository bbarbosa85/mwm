Get started

1

Install

Download MWM, drag it into Applications and open it. It lives in the menu bar. Needs macOS 12 or later.

2

Open it once

macOS may warn that MWM isn't notarized. Choose Privacy & Security → Open Anyway, or right-click MWM and choose Open.

3

Allow Accessibility

So MWM can move windows. Turn on MWM under Privacy & Security → Accessibility.

Prefer Terminal for step 2? 
xattr -dr com.apple.quarantine /Applications/MWM.app

Your first shortcut

MWM already has some shortcuts to try. To add your own:

  1. Menu bar icon → Configure MWM… → Keyboard.
  2. Click a free key and choose Add Shortcut. Pick what it does.
  3. Record the keys, press Save, then Apply and Restart.
Or start from an example.
Editing shortcut

Put a window in part of the screen

Snap the window you are using to a half, a third, a corner or any area. Each area is called a slot.

In the app
  1. Add a shortcut (how) and choose Move to.
  2. Pick a slot. Halves, thirds and quarters are built in.
Need your own area? Slots → New Slot: drag on the picture, or type exact values. Switch a size to px, center it, or add margins to leave space around the slot.
In the file
bindings:
  - key: left
    mods: hyper
    action: {type: move, slot: lefthalf}

slots:                      # your own areas
  center: {x: 20%, y: 0%, width: 60%, height: 100%}

Jump to an app

Bring any app to the front with one shortcut.

In the app
  1. Add a shortcut (how) and choose Focus app.
  2. Type the app's name exactly as the menu bar shows it, such as Google Chrome.
The app must already be running. MWM does not open closed apps.
In the file
  - key: s
    mods: [alt, shift]
    action: {type: focus-app, app: Safari}

Work with more than one screen

Name each screen once. MWM remembers the names, even after you unplug and reconnect.

Give each screen a name. Then send a window to desk, or to the next screen.

In the app
  1. Open Displays, press Add next to a screen, and name it (laptop, desk).
  2. Add a shortcut: Move to with that screen under On screen, or Throw to screen to send the window to the next one.
If a named screen is missing, MWM uses the one you are on.
In the file
monitors:
  laptop: {display: built-in}
  desk: {display: "Studio Display"}

bindings:
  - key: tab
    mods: hyper
    action: {type: throw, screen: next}
  - key: left
    mods: shyper
    action: {type: move, slot: lefthalf, screen: desk}

Save and restore your desktop

A snapshot remembers where every window is. Bring any of them back in a click or with a shortcut.

In the app
  1. Arrange your windows. Open Snapshots, name the New snapshot card and press Save.
  2. Press Restore on a card to put everything back.
  3. Click the pin to keep it after restart. Without it, MWM forgets the snapshot when it quits.
For a shortcut, choose Save snapshot or Restore snapshot.
In the file
  - key: s
    mods: shyper
    action: {type: save-snapshot, name: work, keep: true}
  - key: w
    mods: hyper
    action: {type: restore-snapshot, name: work}

Resize, nudge and push

Fine-tune a window without the mouse.

In the app
  1. Add a shortcut (how) and choose Resize, Nudge or Push.
  2. Say how much: pixels (+50) or percent of the screen (+10%).
In the file
  - key: right
    mods: alt
    action: {type: resize, x: +10%, y: +0}
  - key: up
    mods: [shift, alt]
    action: {type: nudge, x: +0, y: -10%}
  - key: left
    mods: [ctrl, cmd]
    action: {type: push, direction: left, options: "bar-resize:screenSizeX/3"}

Jump to any window with hints

Show a letter on every window, then press one to jump there. Built in on ⌘esc.

Press the shortcut. A letter appears on every window. Press a letter to jump there.

In the app
  1. Add a shortcut (how) and choose Window hints.
  2. Press the shortcut, then a letter.
In the file
  - key: esc
    mods: cmd
    action: {type: hint, letters: ASDFJKL}

The "hyper" key and modifier groups

A modifier group is a name for a set of modifier keys. The most common is hyper.

⌃+⌥+⌘=hyper
In the app
  1. Open Modifiers and press New Group. Click the modifier keys you want on the keyboard, name the group, and press Save.
  2. When you add a shortcut, pick the group by name.
MWM comes with two groups ready to use, altcmd (⌥⌘) and shiftcmd (⇧⌘). If a change to a group would make shortcuts clash, or land on keys macOS keeps, the editor warns you before you save.
In the file
modifiers:
  hyper: [ctrl, alt, cmd]
  shyper: [shift, ctrl, alt, cmd]

bindings:
  - key: left
    mods: hyper          # a group
  - key: f
    mods: [alt, shift]   # or the keys

The settings file

Everything you set is saved in ~/.mwm.yml. You never have to open it. It holds no code, so nothing in it can run.

settings

Everyday options.

modifiers

Key groups, like hyper.

monitors

Screen names.

slots

Your own areas.

aliases

Reusable text. Rarely needed.

bindings

The shortcuts.

  • The app and the file always agree. After editing the file, press Apply and Restart or choose Reload Configuration.
  • Saving in the app rewrites the file, so # comments are lost. Use a shortcut's note instead.
  • Names are shared by groups, screens, slots and aliases, so each name is used once. In free text, write a name as ${name}.
  • Each shortcut can also have group, note, enabled: false and repeat.

Slot formulas advanced

Margins, pixel sizes and centering are set with fields in Slots, and MWM writes the formula for you. You only need to write one by hand for something those fields can't say.

aliases:
  gap: "14"
slots:
  padded: {formula: "move screenOriginX+${gap};screenOriginY+${gap} screenSizeX-2*${gap};screenSizeY-2*${gap}"}

A formula is move x;y width;height. Numbers can use the names below, with no spaces inside a number (screenSizeX/2). An alias is reusable text, written ${name}. A formula written by hand opens in Slots as text, with a preview and a plain message when something is wrong. After the sizes you can add a screen, like move 0;0 1200;800 ${monitor-desk-size}.

screenOriginX screenOriginYTop-left corner of the screen
screenSizeX screenSizeYScreen width and height
windowTopLeftX windowTopLeftYWhere the window is now
windowSizeX windowSizeYThe window's size
newWindowSizeX newWindowSizeYThe window's size after it is resized

Coming from Slate

MWM is a fork of Slate, and your old settings still work.

  • ~/.slate and ~/.slate.yml are converted to ~/.mwm.yml on first launch. The old files are kept as backups.
  • JavaScript settings (~/.slate.js) can't be converted, because MWM no longer runs code from settings.
  • Classic commands (chain, shell …) still work as Advanced… actions. See the operations reference.

Something is wrong

My windows don't move

Check System Settings → Privacy & Security → Accessibility. If MWM is on, remove it with −, add it again, then choose Reload Configuration.

A shortcut does nothing
  • Press Apply and Restart after changing shortcuts.
  • Look for a conflict (orange on the map, or the list's Conflicts filter).
  • For Focus app, the app must be running, with its exact name (Google Chrome).
The window shows an error

The bottom bar names the line. Fix it in a text editor and reopen the window.

I want to start over

Quit MWM and move ~/.mwm.yml aside. MWM starts with its defaults.
