Get started

1

Install

Download MWM, drag it into Applications and open it. It lives in the menu bar. Needs macOS 12 or later.

2

Open it once

macOS may warn that MWM isn't notarized. Choose Privacy & Security → Open Anyway, or right-click MWM and choose Open.

3

Allow Accessibility

So MWM can move windows. Turn on MWM under Privacy & Security → Accessibility.

Prefer Terminal for step 2? 
xattr -dr com.apple.quarantine /Applications/MWM.app

Your first shortcut

MWM already has some shortcuts to try. To add your own:

  1. Menu bar icon → Settings… → Bindings, then New Shortcut (or click a free key and choose Add Shortcut).
  2. Record the keys at the top, then pick what it does: Focus app, Move to slot, Throw to screen or Push. More actions has the rest.
  3. Press Save, then Apply and Restart.
Or start from an example.
Editing shortcut

Put a window in part of the screen

Snap the window you are using to a half, a third, a corner or any area. Each area is called a slot.

In the app
  1. Add a shortcut (how) and choose Move to slot.
  2. Pick a slot. Halves, thirds and quarters are built in.
Need your own area? Slots → New Slot: drag the slot on the picture and drag a handle to resize it (hold ⇧ to keep its proportions, ⌥ to ignore the grid), or type exact values. Switch a size to px, center it, or add margins to leave space around the slot.
In the file
bindings:
  - key: left
    mods: hyper
    action: {type: move, slot: lefthalf}

slots:                      # your own areas
  center: {x: 20%, y: 0%, width: 60%, height: 100%}

Jump to an app

Bring any app to the front with one shortcut.

In the app
  1. Add a shortcut (how) and choose Focus app.
  2. Pick the app from the list, or type its name exactly as the menu bar shows it, such as Google Chrome.
The app must already be running. MWM does not open closed apps.
In the file
  - key: s
    mods: [alt, shift]
    action: {type: focus-app, app: Safari}

Work with more than one screen

Name each screen once. MWM remembers the names, even after you unplug and reconnect.

Give each screen a name. Then send a window to desk, or to the next screen.

In the app
  1. Open Displays, press Add next to a screen, and name it (laptop, desk).
  2. Add a shortcut: Move to slot with that screen under On screen, or Throw to screen to send the window to the next one. Choose its Window size: fill the screen, keep its size, or a custom size.
Screen lists also show every connected display; one with no name yet is named for you when you save. Manage displays… opens the Displays page. If a named screen is missing, MWM uses the one you are on.
In the file
monitors:
  laptop: {display: built-in}
  desk: {display: "Studio Display"}

bindings:
  - key: tab
    mods: hyper
    action: {type: throw, screen: next}
  - key: left
    mods: shyper
    action: {type: move, slot: lefthalf, screen: desk}

Save and restore your desktop

A snapshot remembers where every window is. Bring any of them back in a click or with a shortcut.

In the app
  1. Arrange your windows. Open Snapshots, name the New snapshot card and press Save.
  2. Press Restore on a card to put everything back.
  3. Click the pin to keep it after restart. Without it, MWM forgets the snapshot when it quits.
For a shortcut, choose Save snapshot or Restore snapshot.
In the file
  - key: s
    mods: shyper
    action: {type: save-snapshot, name: work, keep: true}
  - key: w
    mods: hyper
    action: {type: restore-snapshot, name: work}

Keep several profiles

Keep one setup for each desk or computer and switch between them. Only one is active at a time, and MWM uses that one.

In the app
  1. The button at the left of the bottom bar shows the profile the pages edit. Open it to choose another one, or Manage profiles… for all of them as cards. Manage profiles is also the last item of the sidebar.
  2. Choosing a profile only changes what the window edits. MWM starts using it when you press Apply and Restart; until then the bar says not applied. If you close the window first, it asks whether to apply or drop the choice.
  3. On the Profiles page, press Add profile and choose where it comes from: what is running now, a copy of one of your profiles, or a file you downloaded, such as an example. Then pick a name; a short summary shows what the profile holds. The copy icon on a card goes straight to naming. Rename and the trash icon are on each card.
The running profile, the one being edited and the last one can't be deleted, and a deleted one goes to the Trash. Snapshots are shared by every profile.
In the file
~/.mwm/default.mwm.yaml
~/.mwm/desk.mwm.yaml
~/.mwm/active          # the name of the active one

Back up your setup

Keep every profile, and your snapshots, in a private GitHub gist, and bring them to another computer. Backup is a sync: it makes your ~/.mwm folder and the gist match.

In the app
  1. Open Backup and choose Create token on GitHub. The page opens with the gist permission ticked. It has to be a classic token; generate it, copy it and paste it into MWM. It's kept in your Keychain.
  2. Choose Sync now, here or in the Backup menu. MWM sends what changed on this computer and receives what changed in the gist. The list under it shows where each profile stands.
  3. If a profile changed in both places, the newer one wins, and the other is kept as a .bak copy next to it. A sync never deletes anything by itself: when a profile was deleted on one side, MWM asks whether to clear it everywhere or keep it and bring it back.
Snapshots sync too. Which profile is active doesn't: each computer picks its own.
In your gist
default.mwm.yaml
desk.mwm.yaml
snapshots.json
mwm-sync.json          # when each file was last sent

Resize, nudge and push

Fine-tune a window without the mouse.

In the app
  1. Add a shortcut (how) and choose Resize, Nudge or Push.
  2. Say how much: pixels (+50) or percent of the screen (+10%).
  3. For Push, pick a style: keep its size, centered, a full bar, or a bar with a set thickness. The thickness is a percent of the screen, pixels, or 1 of N (3 is a third). A small picture shows where the window goes, and the line it writes.
In the file
  - key: right
    mods: alt
    action: {type: resize, x: +10%, y: +0}
  - key: up
    mods: [shift, alt]
    action: {type: nudge, x: +0, y: -10%}
  - key: left
    mods: [ctrl, cmd]
    action: {type: push, direction: left, options: "bar-resize:screenSizeX/3"}

Jump to any window with hints

Show a letter on every window, then press one to jump there. Built in on ⌘esc.

Press the shortcut. A letter appears on every window. Press a letter to jump there.

In the app
  1. Add a shortcut (how) and choose Window hints.
  2. Press the shortcut, then a letter.
In the file
  - key: esc
    mods: cmd
    action: {type: hint, letters: ASDFJKL}

The "hyper" key and modifier groups

A modifier group is a name for a set of modifier keys. The most common is hyper.

⌃+⌥+⌘=hyper
In the app
  1. Open Modifiers and press New Group. Click the modifier keys you want on the keyboard, name the group, and press Save.
  2. When you add a shortcut, pick the group by name.
MWM comes with two groups ready to use, altcmd (⌥⌘) and shiftcmd (⇧⌘). If a change to a group would make shortcuts clash, or land on keys macOS keeps, the editor warns you before you save.
In the file
modifiers:
  hyper: [ctrl, alt, cmd]
  shyper: [shift, ctrl, alt, cmd]

bindings:
  - key: left
    mods: hyper          # a group
  - key: f
    mods: [alt, shift]   # or the keys

The Settings window

Open it with Settings… or ⌘,. Changes save as you go. Press Apply and Restart to start using them. The button in the bottom bar shows the profile you are editing; the pages under Keyboard, Screens and Options belong to it, while Snapshots, Profiles and Backup under Other are used by every profile.

The settings file

Everything you set is saved in the active profile, a file in ~/.mwm such as ~/.mwm/default.mwm.yaml. You never have to open it. It holds no code, so nothing in it can run.

settings

Everyday options.

modifiers

Key groups, like hyper.

monitors

Screen names.

slots

Your own areas.

aliases

Reusable text. Rarely needed.

bindings

The shortcuts.

  • The app and the file always agree. After editing the file, press Apply and Restart or choose Reload Configuration.
  • Saving in the app rewrites the file, so # comments are lost. Use a shortcut's note instead.
  • Names are shared by groups, screens, slots and aliases, so each name is used once. In free text, write a name as ${name}.
  • Each shortcut can also have group, note, enabled: false and repeat.

Slot formulas advanced

Margins, pixel sizes and centering are set with fields in Slots, and MWM writes the formula for you. You only need to write one by hand for something those fields can't say.

aliases:
  gap: "14"
slots:
  padded: {formula: "move screenOriginX+${gap};screenOriginY+${gap} screenSizeX-2*${gap};screenSizeY-2*${gap}"}

A formula is move x;y width;height. Numbers can use the names below, with no spaces inside a number (screenSizeX/2). An alias is reusable text, written ${name}. A formula written by hand opens in Slots as text, with a preview and a plain message when something is wrong. After the sizes you can add a screen, like move 0;0 1200;800 ${monitor-desk-size}.

screenOriginX screenOriginYTop-left corner of the screen
screenSizeX screenSizeYScreen width and height
windowTopLeftX windowTopLeftYWhere the window is now
windowSizeX windowSizeYThe window's size
newWindowSizeX newWindowSizeYThe window's size after it is resized

Coming from Slate

MWM is a fork of Slate, and your old settings still work.

  • The first time MWM opens with the ~/.mwm folder, ~/.slate, ~/.slate.yml and a ~/.slate.js written by the old configuration window are converted into a profile called default. Your Slate files are only read: MWM never renames, moves or changes them. If you already had a ~/.mwm.yml, it moves into ~/.mwm as default and the Slate import becomes a second profile, slate-import.
  • Any other JavaScript in ~/.slate.js can't be converted, because MWM no longer runs code from settings.
  • In Advanced…, a move or push action shows where it puts a window, names mistakes in plain words, and has a ? button listing these names. Classic commands (chain, shell …) still work there as text. See the operations reference.

Something is wrong

My windows don't move

Check System Settings → Privacy & Security → Accessibility. If MWM is on, remove it with −, add it again, then choose Reload Configuration.

A shortcut does nothing
  • Press Apply and Restart after changing shortcuts.
  • Look for a conflict (orange on the map, or the list's Conflicts filter).
  • For Focus app, the app must be running, with its exact name (Google Chrome).
The window shows an error

The bottom bar names the line. Fix it in a text editor and reopen the window.

I want to start over

Quit MWM and move the active profile (~/.mwm/default.mwm.yaml, or the one named in ~/.mwm/active) aside. MWM starts with its defaults. Or make a New profile under Manage profiles… and apply it.
