Version 1.2 · macOS 12 or later · Apple silicon and Intel

New in 1.2

What changed since 1.1.

☁️

Backup

Save your shortcuts, slots and snapshots to a private GitHub gist, one backup for each set of displays, and restore any of them. How backup works.

⬇️

Updates in place

Update now downloads the new version, checks it against its checksum and the app’s signature, then restarts into it. The menu bar.

🧭

A tidier menu bar

Settings… (it was Configure MWM…), a Backup submenu to restore a backup in one click, and Launch MWM at Login right under your shortcuts.

💬

One look for every alert

Confirmations, warnings and results share one design, with clear buttons and a red one for anything that deletes.

📐

A steady window

The settings window keeps its width, so pages no longer jump around as you move between them.

Shortcuts

Set a key to do something, and see it all at a glance.

⌨️

Keyboard map

Every shortcut on a picture of a Mac keyboard, colored by what it does, for each modifier group.

📋

A searchable list

Prefer rows? The list shows every shortcut and filters as you type.

⏺️

Record or pick

Press the keys to record a shortcut, or click a key on the map.

⚠️

Conflicts flagged

Two shortcuts on the same keys, or keys macOS already uses, are flagged before they cause trouble.

✦

Hyper and other groups

Name a group of modifiers, like ⌃⌥⌘, and use it for as many shortcuts as you like.

🎁

Good defaults

Resize, nudge, focus, and jump to Finder, Safari, Terminal and more work out of the box. See them.

Moving windows

Put a window exactly where you want it.

▦

Slots

Halves, thirds, quarters, or any area you draw. Nineteen presets are built in.

✏️

Draw, don’t type

Drag the edges of a slot on a picture of your screen, or type exact percentages. It snaps to a grid and previews on each connected screen.

↔️

Resize, nudge and push

Grow or shrink a window by a step, nudge it, or push it to a screen edge.

🔎

Window hints

Show a letter on every window and press it to jump there.

🎯

Focus by direction

Move focus to the window on the left, right, above or below.

🚀

Jump to an app

One key brings Finder, Safari, Terminal or any app you choose to the front.

Displays

Work with more than one screen.

🖥️

Names that stick

Give each screen a name. Shortcuts that use it keep working after you unplug and reconnect.

📤

Throw to another screen

Send a window to the next screen, or to one by name.

👁️

Preview on any screen

Slots are drawn on each of your connected screens while you edit.

Snapshots

Save the whole desktop.

📸

Save and restore

Remember where every window is and the screens it was on. Restore it from the window, the menu bar or a shortcut.

🖼️

Live pictures

Each card shows the windows with each app’s icon.

📌

Keep after restart

Pin a snapshot so it survives MWM restarting.

🔄

Update in place

Replace a snapshot with the windows you have now.

Backup

Your setup, somewhere safe.

☁️

A private gist

Backups go to one private gist on your GitHub account. The token stays in your Keychain.

🏷️

One backup per setup

Name each set of displays, like Desk, two monitors. A name that already exists replaces that backup.

✅

Matches your displays

The backup that fits the screens you have connected is marked.

🛟

Restore with a safety copy

Restoring replaces your shortcuts, slots and snapshots and keeps a copy of your current file next to it.

Yours to keep

Plain, private and open.

📄

One readable file

Everything lives in ~/.mwm.yml. Edit it in the app or in any editor.

🔒

Nothing runs from it

The file is plain data. MWM never runs code from it.

📥

Comes from Slate

Slate and Slate YAML settings are converted on first launch. Moving from Slate.

🌐

Quiet on the network

MWM only talks to GitHub for new versions and for your own backup, and you can turn the update check off. Open source under GPLv3.
