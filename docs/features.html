Features

Find what you want to do, see it, then open the docs for the steps.

Shortcuts

Set a key to do something, and see it all at a glance.

See every shortcut at a glance

A keyboard map, colored by what each key does, for each modifier group. A Key colors button explains the colors.

Find one fast

A searchable list that filters as you type.

Add a shortcut by pressing it

Record the keys, or click a key on the map. New Shortcut is always one click away.

Pick what it does from a few cards

Focus app, Move to slot, Throw to screen and Push come first. The rest are under More actions.

Know when two shortcuts clash

Two shortcuts on the same keys, or keys macOS already uses, are flagged before they cause trouble.

Use one key group for everything

Name a group of modifiers and use it for as many shortcuts as you like.

Start with good defaults

Resize, nudge, focus, and jump to Finder, Safari or Terminal work out of the box.

Read the docs

Moving windows

Put a window exactly where you want it.

Put a window in part of the screen

Halves, thirds, quarters, or any area you draw. Nineteen presets are built in.

Draw an area instead of typing numbers

Drag a slot on a picture of your screen and drag its handles to resize. It snaps to a grid, and Shift keeps its proportions.

Grow, shrink or nudge

By a step, or push a window to a screen edge.

Jump to any window with a letter

Window hints show a letter on every window.

Move focus by direction

To the window on the left, right, above or below.

Jump to an app

One key brings Finder, Safari, Terminal or any app you choose to the front.

Read the docs

Displays

Work with more than one screen.

Name your screens

Names stick, even after you unplug and reconnect.

Send a window to another screen

To the next screen, or to one by name, filling it or keeping the window's size.

Every connected display is on the list

Pick one that has no name yet and MWM names it for you when you save.

Preview slots on any screen

Slots are drawn on each of your connected screens while you edit.

Read the docs

Snapshots

Save the whole desktop.

Get my whole desktop back

Restore it from the window, the menu bar or a shortcut.

See what is in each snapshot

Live pictures of the windows, with each app’s icon.

Keep one after MWM restarts

Pin a snapshot so it survives a restart.

Update one with today’s windows

Replace a snapshot with the windows you have now.

Read the docs

Profiles

Keep a setup for each desk or computer.

Keep one setup for each desk

Each profile is its own file in ~/.mwm. Only one is active at a time.

Choose, then apply

Pick a profile from the button in the bottom bar of Settings. MWM switches to it when you press Apply and Restart.

Start from a copy or from the defaults

Make a new one, duplicate one you have, or add a file you downloaded, such as an example.

Bring your Slate setup, untouched

It is imported once, as its own profile. MWM never renames or changes your Slate files.

Read the docs

Backup

Your profiles, somewhere safe.

Keep my profiles in a private gist

One private gist on your GitHub account holds every profile. The token stays in your Keychain.

Sync with one button

Sync now sends what changed here and receives what changed there, from the Backup page or the menu bar.

See where each one stands

A list shows each profile as synced, changed here, newer in the gist, or only on one side.

Never lose the other copy

The newer one wins and the other is kept as a .bak. Deleted ones are never removed without asking.

Read the docs

Yours to keep

Plain, private and open.

Read and edit one plain file

Each profile is one file in ~/.mwm. Edit it in the app or in any editor.

Nothing runs from it

The file is plain data. MWM never runs code from it.

Bring my Slate settings

Slate and Slate YAML settings are converted on first launch.

Stay quiet on the network

MWM talks to GitHub only for new versions and your own backup, and you can turn the update check off.
