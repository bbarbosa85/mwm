Changelog

What changed in each version of MWM. Newest first.

1.3

LatestNovember 26, 2026Release notes
  • A redesigned Settings window. A new sidebar (Keyboard, Screens, Options, Other) that the menu bar follows, a fixed width so pages never jump, and a profile button in the bottom bar.
  • Easier shortcuts. Keys come first, then four action cards (Focus app, Move to slot, Throw to screen, Push) and a "More actions" list. Throw and Push choose their window size and style with cards, and every connected display is on the screen lists.
  • A better slot editor. Drag and resize on a full-width picture (Shift keeps proportions), with position, size and margins in settings blocks.
  • Profiles. Keep one for each desk, switch between them, and sync them with a private GitHub gist. An existing Slate setup is imported without being changed.
  • Key colors explains the keyboard map, and New Shortcut is always one click away.
  • Documentation. A shorter README, a Settings window guide, and refreshed site pages.

1.2

November 24, 2026Release notes
  • Backup. Keep your configuration, snapshots and displays in a private GitHub gist, one backup for each set of displays, and restore any of them from the new Backup page or the menu bar. The token stays in your Keychain, and restoring keeps a copy of your current file.
  • Updates install themselves. "Update now" downloads the new version, checks it, and restarts into it.
  • A tidier menu bar. "Settings…" (was "Configure MWM…"), a Backup submenu, and "Launch MWM at Login" under your shortcuts.
  • One design for every alert, and a settings window that keeps its width.
  • New site pages. A features page, and the docs and examples pages share one look.

1.1

November 23, 2026Release notes
  • Slots with formulas. Slots written as formulas open in the editor. New slots pick Simple (position, size in % or pixels, centering, margins) or Advanced (a formula, with a help popover, the result in pixels and plain-language checks).
  • Push controls. Push has a style (keep its size, centered, full bar, bar with a set thickness), a thickness in %, pixels or 1 of N, and a screen, with a preview.
  • Checks for advanced actions. Move and push text shows where it puts a window and names mistakes.
  • A larger minimum size for the configuration window.

1.0

November 22, 2026Release notes
  • The first MWM release, a fork of Slate renamed to MWM with a new icon and signing.
  • A Settings window instead of a config language: a keyboard map and list, a shortcut recorder and action editors, a Displays page with screen names, Slots with presets and an editor, and a Snapshots page.
  • A tidier menu bar, one design for alerts, and an About window.
  • A configuration format with plain names and lists, converted automatically on launch.
  • A website with docs, examples and the downloads, and default shortcuts to start with.
